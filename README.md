# SMART CRIME MAPPING DATA ANALYSIS AND PREDICTIVE INSIGHTS

An interactive spatial-temporal crime data science and predictive analytics platform developed for **Department of CSE (Data Science)** at **Geethanjali Institute of Science & Technology (Autonomous)**.

---

## 📌 1. Project Overview

The **Smart Crime Mapping & Predictive Insights** system is a full-stack data analytics and machine learning application engineered to analyze historical incident patterns, visualize geographic crime concentrations, evaluate multi-class classification algorithms, and generate academic research reports.

### Academic & Ethical AI Declaration
> [!IMPORTANT]
> **Ethical & Academic Compliance**: Predictions generated by this system are aggregate statistical estimates based on historical features (district, temporal period, historical density). The platform strictly prohibits individual tracking, facial recognition, person-level risk profiling, and automated policing actions.

## ⚡ Netlify Cloud Serverless Deployment

This platform is configured for **simultaneous fullstack deployment on Netlify**:
- **Frontend SPA**: React 18 + Vite builds to `dist/` with edge redirects (`/* -> /index.html 200`).
- **Serverless REST API**: Express backend runs as a high-performance Netlify Function (`netlify/functions/api.js`).
- **Edge Routing**: `/api/*` automatically proxies to `/.netlify/functions/api/:splat` under the same domain.
- For complete instructions, see the **[Netlify Deployment Guide](./NETLIFY_DEPLOYMENT_GUIDE.md)**.

## 🚀 5. Getting Started & Installation

### Prerequisites
- Node.js (v18.x or later)
- npm (v9.x or later)
- *(Optional)* Local MongoDB or MongoDB Atlas URI (If not present, the system automatically uses an embedded in-memory MongoDB instance with zero manual setup required!)

### Step 1: Install Backend Dependencies
```bash
cd backend
npm install
```

### Step 2: Install Frontend Dependencies
```bash
cd ../frontend
npm install
```

### Step 3: Seed Database (Optional — Done Automatically on First Boot)
```bash
cd ../backend
npm run seed
```

### Step 4: Run Backend Development Server
```bash
cd ../backend
npm run dev
```
*Backend runs on: `http://localhost:5000`*

### Step 5: Run Frontend Development Server
```bash
cd ../frontend
npm run dev
```
*Frontend runs on: `http://localhost:5173`*

## 🧠 7. Machine Learning Methodology

The platform implements 3 distinct multi-class classification algorithms:

### 1. Random Forest Classifier
- **Ensemble Architecture**: 20 Decision Trees constructed using bootstrap sampling with replacement (Bagging).
- **Feature Sampling**: Sub-feature selection per node split to minimize tree correlation.
- **Explainability**: Gini impurity decrease weighted across all trees to compute feature importance rankings.

### 2. CART Decision Tree Classifier
- **Criterion**: Gini Impurity $I_G(p) = 1 - \sum_{i=1}^C p_i^2$.
- **Recursive Splitting**: Depth tuned ($d_{max} = 8$) and minimum sample split ($s_{min} = 4$) to prevent overfitting.

### 3. Multinomial Logistic Regression (Softmax)
- **Activation Function**: $\sigma(z)_i = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}$.
- **Regularization**: $L_2$ penalty parameter to penalize extreme weight vectors.

### Evaluation Metrics
- **Multi-Class Confusion Matrix ($K \times K$)**: Full error matrix tracking actual vs. predicted classes.
- **Accuracy**: $\frac{\sum \text{True Positives}}{\text{Total Samples}}$.
- **Macro-Averaged Precision, Recall, and F1-Score**: Evaluates unweighted class averages to protect against minority category bias.

## 📡 8. REST API Reference

| Endpoint | Method | Role | Description |
| :--- | :--- | :--- | :--- |

| `/api/dashboard/insights`| `GET` | Authenticated | Auto-generate textual statistical insights |

| `/api/map/area-stats` | `GET` | Authenticated | Retrieve deep dive statistics for selected district |
| `/api/ml/train` | `POST` | Authenticated | Train and evaluate all ML models |
| `/api/ml/predict` | `POST` | Authenticated | Generate aggregate crime category prediction |
| `/api/ml/results` | `GET` | Authenticated | Retrieve comparison metrics and confusion matrix |
| `/api/datasets/upload` | `POST` | Authenticated | Upload and clean CSV dataset |
| `/api/reports/generate` | `POST` | Authenticated | Compile comprehensive academic PDF/HTML report |
